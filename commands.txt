1) Я использовал команду git init для инициализации гита
2) После я задал глобально себе имя и почту с помощью git config --global user.name и user.email
3) По инструкции использовал git checkout для того чтобы перейти с ветки master на ветку home_work_25
4) После каждых изменений я использовал git add -A для добавление файлов в отслеживание
5) Потом я коммитил свои изменения с помощью команды git commit -m "мой комментарий коммита"
6) Также использовал приставку -a в git commit -a -m чтобы одной командой добавлять файлы и коммитить изменения
7) В конце я использовал команду git merge для слияния веток
